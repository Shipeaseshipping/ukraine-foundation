# Humanitarian foundation website

React + TypeScript + Vite. All organization-specific values are provisional. Edit `src/content.ts` for identity, program descriptions, imagery, groups, documents, and navigation. Replace proposed page copy in `src/main.tsx` with approved text.

## Development

Install packages with `pnpm install`, run `pnpm dev`, and build with `pnpm build`. Serve `dist` with an SPA fallback to `index.html` for nested routes.

## Launch requirements

Provide the official identity, verified organizational history, program details, statistics with reporting periods, consented stories, authorized photographs, leadership biographies, registration documents, public contact details, and reviewed policies. The current documentary images are illustrative third-party references, credited in the interface, and must be replaced with authorized foundation imagery before public launch.

Payments and contact submission are deliberately disconnected. Never collect card data directly. Connect an authorized payment provider and a secure contact endpoint, add server validation and abuse prevention, and activate honest receipt/success/error states only after testing delivery. Ukrainian is visibly pending; add approved translations before enabling the locale. No analytics are installed. Google Fonts and remote photos make external browser requests.

The globe is a lightweight CSS decoration, not a coverage map. All impact figures are placeholders. The preview is intended to remain private pending verification.
